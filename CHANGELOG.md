# Changelog

## v0.1.0-beta

Initial beta release.

### Included

- First 7 Days simulation
- Ward Tour
- Station Practice
- Patient Cases
- SBAR practice
- Job Tracks
- Korean/English support
- Visual hospital-space assets
- Feedback link structure
- Bundled Noto Sans KR font for more consistent Korean UI rendering across Windows systems

### Known limitations

- This is a beta educational simulation.
- Content may not reflect every state, hospital, or facility policy.
- Clinical scenarios are simplified for educational use.
- Google Form feedback URL is connected for beta review collection.
- The Windows executable is unsigned, so SmartScreen may warn users.
