# U.S. Ward Experience Lab v0.1.1-beta

This beta refresh updates the Windows desktop simulation and the screenshots in the repository.

## What changed

- Cleaner, more compact navigation and page layouts.
- Improved presentation of First 7 Days, Ward Tour, and practice activities.
- Saved drafts and progress for supported exercises, including SBAR practice.
- Screenshots captured from the running application at the supported 1180 × 700 layout.

Download the attached `USWardExperienceLab_v0.1.1-beta.exe` for Windows. The executable is unsigned, so Windows SmartScreen may display a warning. The macOS build workflow is experimental and has not been verified for this release.

This is an independent educational simulation, not a clinical decision tool or an official NCLEX product. Do not enter real patient or other personal information.
