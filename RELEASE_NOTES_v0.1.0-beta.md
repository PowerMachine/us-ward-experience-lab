# U.S. Ward Experience Lab v0.1.0-beta

This is the first beta release of U.S. Ward Experience Lab.

이 프로그램은 미국 이민/취업을 준비하는 한국 RN이 미국 병동 workflow를 미리 체험할 수 있도록 만든 Windows 교육용 시뮬레이션입니다.

## Included

- First 7 Days simulation
- Ward Tour
- Station Practice
- Patient Cases
- SBAR practice
- Job Tracks
- Korean/English support
- Visual hospital-space assets
- Feedback button structure

## Download

Download:

[USWardExperienceLab_v0.1.0-beta.exe](release-assets/USWardExperienceLab_v0.1.0-beta.exe)

Windows SmartScreen warning may appear because this is an unsigned beta executable.

## macOS Experimental Build

An unsigned macOS build workflow is included for testing:

```text
.github/workflows/build-macos.yml
```

The generated `USWardExperienceLab_macos_unsigned_v0.1.0-beta.zip` artifact is not signed or notarized. macOS may block it with an unidentified developer warning.
